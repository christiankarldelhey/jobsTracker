# Frontend Job Skills Analyzer 📊

Aplicación web gratuita para analizar ofertas de trabajo de Frontend Developer y descubrir qué tecnologías y skills son más demandadas.

## 🚀 Características

- **Análisis inteligente**: Pega cualquier oferta de trabajo en inglés o castellano
- **Detección de tecnologías**: Reconoce más de 100 tecnologías y sus variantes (React, React.js, ReactJS, etc.)
- **Visualización clara**: Gráfico de barras interactivo con porcentajes
- **Historial acumulativo**: Guarda todas tus búsquedas para ver tendencias generales
- **100% gratis**: Sin límites, sin registro

## 📦 Instalación

```bash
npm install
```

## 🏃 Ejecutar en desarrollo

```bash
npm run dev
```

## 🏗️ Build para producción

```bash
npm run build
```

## 💡 Cómo usar

1. Copia una oferta de trabajo de frontend developer
2. Pégala en el área de texto
3. Haz clic en "Analizar Oferta"
4. Ve las estadísticas de tecnologías demandadas
5. Analiza múltiples ofertas para obtener tendencias más precisas

## 🛠️ Tecnologías usadas

- React 18
- TypeScript
- TailwindCSS
- Recharts (gráficos)
- Vite
- Lucide React (iconos)
